# 🏏 IPL Analytics Dashboard | Power BI

An interactive **IPL Analytics Dashboard** built using **Power BI, DAX, Power Query, and Data Modeling** to analyze IPL performance from **2008 to 2025**.

The project analyzes **1,169 IPL matches and 278K+ ball-by-ball deliveries** to provide insights into team performance, player statistics, match outcomes, venues, toss decisions, and season-wise trends.

---

## 📌 Project Overview

The objective of this project is to transform raw IPL match and ball-by-ball data into an interactive business-style dashboard that helps users understand:

* Team performance across IPL seasons
* Batting and bowling performance
* Player-level statistics
* Match and toss outcomes
* Venue-wise performance
* Season-wise IPL trends
* Winning and losing patterns

The dashboard allows users to interactively filter and explore IPL data using Power BI.

## 📂 Dataset

The project uses multiple datasets:

| Dataset                       | Description                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------ |
| `ipl_matches_data.csv`        | Match-level information including teams, venue, toss, winner and result        |
| `ball_by_ball_data.csv`       | Ball-by-ball delivery information including batsmen, bowlers, runs and wickets |
| `players-data-updated.csv`    | Player information                                                             |
| `teams_data.csv`              | IPL team information                                                           |
| `IPL Analysis 2008-2025.pbix` | Power BI dashboard file                                                        |

### Dataset Coverage

* **IPL Seasons:** 2008–2025
* **Matches:** 1,169+
* **Ball-by-ball deliveries:** 278K+
* **Players:** 772
* **Batsmen analyzed:** 703
* **Bowlers analyzed:** 550
* **Venues:** 59
* **Teams:** 14

## 🔄 Data Preparation & Modeling

The raw datasets were processed using **Power Query** before being loaded into Power BI.

### Data Preparation Steps

1. Imported multiple CSV datasets into Power BI.
2. Cleaned and transformed raw columns using Power Query.
3. Handled missing and inconsistent values.
4. Standardized team and player information.
5. Created relationships between match, player, team, and ball-by-ball datasets.
6. Developed calculated columns and measures using DAX.
7. Created interactive visualizations and KPI cards.
